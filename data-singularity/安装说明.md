# 安装 · 电脑 / 手机

## 一、电脑（Windows）

**双击 `安装到电脑.bat`** —— 会自动完成：

1. 程序复制到 `%LOCALAPPDATA%\Programs\BlackHole`（不需要管理员权限）；
2. 创建**开始菜单**快捷方式与**桌面**快捷方式（同一颗黑洞图标）；
3. 在「设置 → 应用和功能」里登记 **黑洞 · DATA SINGULARITY 1.0.0**，带发布者、安装位置、图标、大小；
4. 安装目录里生成 `卸载.cmd`。

**卸载**：设置 → 应用 → 黑洞 → 卸载；或直接运行安装目录里的 `卸载.cmd`（会删快捷方式、注册表项和程序目录）。

**运行**：开始菜单 / 桌面双击「黑洞」，打开的是无地址栏的独立窗口（1440×920），关掉窗口即退出。

- 不用安装也能用：文件夹里的 `黑洞.lnk` / `黑洞.cmd` 是便携模式，双击即以同样的窗口打开；
- 电脑没装 Edge / Chrome 时自动退回默认浏览器；
- 独立用户配置目录 `%LOCALAPPDATA%\BlackHoleApp`，不碰你平时的浏览记录。

> 桌面快捷方式若未创建（少数系统限制），把文件夹里的 `黑洞.lnk` 拖到桌面即可；安装脚本会给出提示但不会中断。

## 二、手机（Android / iPhone）

手机端是 **PWA**——不需要 APK，装到桌面就是一个全屏应用。

1. 电脑上双击 **`手机安装.cmd`**，窗口会列出本机 IPv4 地址，并启动 8899 端口的服务；
2. 手机连**同一个 Wi-Fi**，浏览器打开 `http://电脑IP:8899`；
3. 浏览器菜单：
   - **Android Chrome**：`安装应用` / `添加到主屏幕`
   - **iPhone Safari**：分享 → `添加到主屏幕`
4. 桌面出现「黑洞」图标，点开全屏无地址栏；首次加载后**离线可用**（Service Worker 缓存了整个应用）。

首次启动 Windows 可能弹出防火墙提示，选「允许」（专用网络即可）。

> 局域网 HTTP 下，Android 可能只提供「添加到主屏幕」而不是完整的安装登记——图标、全屏、离线都成立；要系统级“已安装”需要 HTTPS，本地没有证书，属于正常现象。

## 三、拷贝给别人

整个 `data-singularity` 文件夹就是完整安装包，拷到任意 Windows 电脑双击 `安装到电脑.bat` 即可。

```
data-singularity/
├─ 安装到电脑.bat          安装（开始菜单 / 桌面 / 应用列表）
├─ install.ps1  uninstall.ps1
├─ 黑洞.cmd / 黑洞.lnk     免安装的便携启动
├─ launch.ps1              app 模式启动
├─ 手机安装.cmd             局域网服务器
├─ 创建快捷方式.cmd          只建一个桌面图标
├─ index.html / app.js     程序本体
├─ assets/  icons/  preview/
├─ manifest.json / sw.js   PWA 安装与离线缓存
└─ 安装说明.md
```
